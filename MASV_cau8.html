Câu 1. JavaScript là gì? Nó được dùng để làm gì trong thiết kế web?

JavaScript là một ngôn ngữ lập trình bậc cao, thông dịch (interpreted), chạy chủ yếu trên trình duyệt web và hiện nay cũng chạy được ở phía máy chủ thông qua Node.js. Cùng với HTML (cấu trúc nội dung) và CSS (giao diện, định dạng), JavaScript là một trong ba công nghệ nền tảng của web, đảm nhiệm phần hành vi và tương tác.

Vai trò của JavaScript trong thiết kế web:

  • Tạo tương tác cho trang web: xử lý sự kiện click, nhập liệu, cuộn trang, di chuột…
  • Thay đổi nội dung và giao diện động: thêm, sửa, xóa phần tử HTML/CSS thông qua DOM mà không cần tải lại trang.
  • Kiểm tra dữ liệu biểu mẫu (form validation) ngay trên trình duyệt trước khi gửi lên máy chủ.
  • Giao tiếp với máy chủ không đồng bộ (AJAX, Fetch API) để lấy hoặc gửi dữ liệu.
  • Tạo hiệu ứng, hoạt ảnh, slider, menu, popup, biểu đồ…
  • Xây dựng ứng dụng web hoàn chỉnh với các framework/thư viện như React, Vue, Angular; phát triển backend với Node.js.

Câu 2. Các kiểu dữ liệu chính trong JavaScript

JavaScript có hai nhóm kiểu dữ liệu: kiểu nguyên thủy (primitive) và kiểu tham chiếu (object).

a) Kiểu nguyên thủy (7 kiểu):

KiểuMô tả / Ví dụ
NumberSố nguyên và số thực. Ví dụ: 10, 3.14, NaN, Infinity
StringChuỗi ký tự. Ví dụ: "Xin chào", 'JS'
BooleanGiá trị logic: true hoặc false
UndefinedBiến đã khai báo nhưng chưa được gán giá trị
NullGiá trị rỗng, được gán chủ động ("không có giá trị")
SymbolGiá trị duy nhất, bất biến, thường dùng làm khóa thuộc tính
BigIntSố nguyên lớn tùy ý. Ví dụ: 123456789012345678901234567890n

b) Kiểu tham chiếu:

  • Object – tập hợp các cặp khóa – giá trị, bao gồm cả Array (mảng), Function (hàm), Date, Map, Set…

Lưu ý: toán tử typeof null trả về "object" – đây là một lỗi lịch sử của JavaScript.

Ví dụ:

var a = 1; var a = 2; // hợp lệ

const c = 1; c = 2; // TypeError: Assignment to constant variable
const arr = [1]; arr.push(2); // hợp lệ: const không cho gán lại biến, nhưng nội dung object/mảng vẫn thay đổi được

Khuyến nghị: ưu tiên dùng const; chỉ dùng let khi cần gán lại giá trị; hạn chế dùng var.

Câu 4. JavaScript có phải là ngôn ngữ đơn luồng không?

Có. JavaScript là ngôn ngữ đơn luồng (single-threaded): engine chỉ có một luồng thực thi chính và một call stack, nên tại một thời điểm chỉ thực hiện được một đoạn mã.

Tuy vậy, JavaScript vẫn xử lý được các tác vụ bất đồng bộ (setTimeout, Fetch, sự kiện…) nhờ cơ chế Event Loop kết hợp với Web APIs (hoặc libuv trong Node.js), Callback Queue và Microtask Queue (Promise). Các tác vụ tốn thời gian được giao cho môi trường (trình duyệt/Node.js) xử lý, khi xong thì callback được đưa vào hàng đợi và Event Loop đẩy vào call stack khi stack trống. Ngoài ra, có thể chạy mã song song bằng Web Workers (trong trình duyệt) hoặc Worker Threads (trong Node.js).

Câu 5. Toán tử delete trong JavaScript có tác dụng gì?

delete là toán tử (operator), không phải hàm, dùng để xóa một thuộc tính khỏi đối tượng (object). Cú pháp: delete object.property hoặc delete object["property"].

Ví dụ:

const user = { name: "An", age: 20 };
delete user.age;
console.log(user); // { name: "An" }

Đặc điểm cần nhớ:

  • Trả về true nếu xóa thành công (hoặc thuộc tính không tồn tại); trả về false nếu thuộc tính không thể cấu hình (non-configurable) – ở strict mode sẽ ném lỗi TypeError.
  • Chỉ xóa được thuộc tính của object; không xóa được biến khai báo bằng var, let, const hay hàm.
  • Khi dùng với phần tử mảng, delete chỉ xóa giá trị và để lại “ô trống” (empty), không làm thay đổi length; nên dùng splice() để xóa hẳn phần tử.
  • Không xóa được thuộc tính của prototype thông qua đối tượng con; chỉ xóa được thuộc tính sở hữu (own property).
